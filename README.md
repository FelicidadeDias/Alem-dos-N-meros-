# Além dos Números

Página de apoio à formação em Contabilidade.

## Publicação
O ficheiro principal do website é `index.html`. O logótipo original do repositório é utilizado directamente no cabeçalho.

Para publicar com GitHub Pages:
1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Seleccione a branch `main` e a pasta `/ (root)`, depois guarde.

O website foi pensado como um espaço simples de informação, materiais de apoio, motivação, respeito e aprendizagem em equipa.
